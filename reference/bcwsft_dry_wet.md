# Dry/wet class from BEC subzone first letter (getDryWet, L325-342)

Dry/wet class from BEC subzone first letter (getDryWet, L325-342)

## Usage

``` r
bcwsft_dry_wet(s)
```

## Arguments

- s:

  named list of VRI attributes for one polygon.

## Value

one of "dry", "wet", "undifferentiated", or "Invalid Subzone".
